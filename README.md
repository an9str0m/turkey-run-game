An original turkey escape game for the make.fun competition
[turkey-run-game-01](https://make.fun/c/turkey-run-game-01): dinner is at six,
and you are **not** on the menu.

You are a turkey with somewhere better to be. Sprint **1,000 m** across the
farm to the Freedom Pines while the farmer closes in behind you — hurdle the
ovens, duck the flying carving knives, splash through (or over) the puddles,
and grab corn to keep your legs — and your lead. Three hits, or one farmer's
hand on your tail feathers, and it is gravy time.

## Play

Serve `game/` with any static file server and open `game/index.html` in a
desktop browser. It plays fully offline: no build step, no network requests,
every sprite and sound is generated by the code itself.

- **Space / W / ↑** — jump (twice for a double jump)
- **↓ / S** — duck under knives, dive faster from a jump
- **Click / tap** — start, jump, restart
- **P** pause · **M** sound on/off · **R** run again

## Layout

- `main.ts` — the hand-in program (Node 22): copies `game/` and
  `screenshots/` to the output directory and writes `dossier.json` with
  `vendor/makefun-game.ts`.
- `game/` — the game as static files: `index.html` plus ES modules in
  `game/src/` (`config`, `random`, `audio`, `input`, `world`, `render`,
  `main`). Canvas 2D vector art and WebAudio-synth sound only.
- `screenshots/` — four real renders of the game (title, a run in play, and
  both endings), staged deterministically from the game's own simulation via
  `?shot=title|play|caught|escaped&seed=7`.
